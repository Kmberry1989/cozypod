# Podling faces

- **Canvas:** exactly 256×256 px, transparent PNG or WebP; do not crop.
- **Registration:** eye centers around (92, 126) and (164, 126); mouth centered
  around (128, 164). Match the built-in files before exporting.
- **Safe bounds:** all face marks within x=65–191 and y=100–190.
- **Art direction:** simple dark chocolate-clay features with soft edges and a
  tiny upper-left highlight; expressions must read clearly at 32 px.
- **Do not include:** body color, headwear, background, text, UI, or skin patch.
