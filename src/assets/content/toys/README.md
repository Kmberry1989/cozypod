# Toys and shelf collectibles

- **Canvas:** 512×512 px recommended; square transparent PNG or WebP.
- **Object bounds:** keep the object within x=48–464 and y=36–460, with its base
  near y=440 so different toys sit consistently on the shelf.
- **Art direction:** one readable clay object, warm upper-left studio light,
  saturated CozyPod palette, soft contact shadow contained inside the canvas.
- **Do not include:** scenery, text, labels, UI, a frame, or multiple objects.
- **Unlocks:** one project shelf toy unlocks per earned trophy, in alphabetical
  filename order. Select unlocked toys in the Wardrobe to display them in the
  clubhouse.
