# Sprouts and rear headwear

- **Canvas:** exactly 256×256 px, transparent PNG or WebP; never trim the canvas.
- **Registration:** stem/attachment centered around x=128, y=55. It may extend up
  to y=8 and down behind the body to y=210.
- **Safe bounds:** x=24–232 and y=8–216.
- **Layering:** this folder renders behind the body. Use it for sprouts, ears,
  rear hair, capes, or accessories whose lower section should be hidden by the body.
- **Art direction:** the same handmade clay and warm upper-left light as the body.
- **Do not include:** a body, face, room, text, UI, or full-canvas shadow. Use
  `podling-hats/` for anything that must cover the forehead or face.
